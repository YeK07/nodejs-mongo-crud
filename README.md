# NodeJS & Express - MongoDB CRUD Uygulaması

**Geliştirici:** Yunus Emre Kızkaban  
**Öğrenci No:** 25580109  
**Ders:** Nesne Tabanlı Node.js

Bu proje, Node.js ve Express framework'ü kullanılarak MongoDB resmi sürücüsü (MongoDB Native Driver) ile geliştirilmiş temel CRUD (Ekle, Sil, Güncelle, Listele) operasyonlarını gerçekleştiren bir web uygulamasıdır. Veritabanı olarak MongoDB Atlas bulut kümesi kullanılmıştır. Arayüz ve API kodları modüler olarak tek bir dosyada birleştirilmiştir.
